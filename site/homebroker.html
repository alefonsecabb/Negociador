💹 Homebroker fictício

← Dashboard carregando...
Carteira fictícia de R$ 100.000, guardada só neste navegador. Cada sugestão de ENTRADA que você marca como "Executar" no dashboard abre uma posição aqui, com uma ordem bracket (stop + take) ativa. As saídas por stop-loss, take-profit e prazo máximo são simuladas automaticamente a cada visita, usando as cotações publicadas (quotes.json, atualizadas ~15 em 15 min) e o mesmo critério do backtest. Não há servidor nem login. Como os dados vivem no localStorage, use Exportar de vez em quando para não perder o histórico se limpar o navegador.
